## 👨‍💻 Sobre Mim

Sou desenvolvedor backend na **Talk Code - Software House**, especializado em **arquiteturas de sistemas de agentes de IA, orquestração de LLMs e ferramentas de linha de comando de alto desempenho**.

-  **Em foco atualmente:** Desenvolvendo sistemas de agentes autônomos com memória contínua, governança de segurança determinística e orquestração de ferramentas.
-  **Arquitetura & Engenharia:** Event Sourcing, Model Context Protocol (MCP), Loops Cognitivos ReAct, busca híbrida (FastEmbed + SQLite FTS5) e TUI/CLI streaming.
-  **DevOps & Infra:** Deploy e orquestração em Linux, Docker, Traefik v3, SSL automatizado e ambientes de alta disponibilidade.
- 💬 **Fale comigo sobre:** Agentes autônomos de IA, engenharia backend com Python, MCP, automação e infraestrutura moderna.
